## Knowledge

- Emulator screenshots in CI: the API 30 `google_apis` x86_64 image with ARM translation is about 3× slower than
  API 35 and hit the 60-min job limit after 3 locales; give it ≥ 90 min or fewer views. API < 33 has no
  `cmd locale set-app-locales`, so the script switches the system locale (`adb root`, `persist.sys.locale`, zygote
  restart). #area/tooling #type/how-to
- On the 360×640 dp emulator a "Pixel Launcher isn't responding" dialog blocked every tap of run 1; the script now
  presses `android:id/aerr_wait` inside its dump helper. Sheet buttons are clickable `TextView`s, not `Button`s –
  tap the last clickable TextView for the positive action (locale-independent). #area/tooling #type/gotcha
