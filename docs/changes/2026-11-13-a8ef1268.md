## Knowledge

- Emulator screenshots in CI: on API 35 a "Pixel Launcher isn't responding" dialog can swallow every tap of a whole
  run; disable the launcher (`pm disable-user --user 0 com.google.android.apps.nexuslauncher`) and set
  `settings put global hide_error_dialogs 1` before installing the app. #area/tooling #type/gotcha
- `input motionevent DOWN … MOVE … UP` does not trigger the scrub bar's segment lift (it scrubs instead), so the
  drag-hint state (A3) cannot be scripted that way. #area/tooling #type/gotcha
- Touch targets can be measured without code: `uiautomator dump` bounds of clickable nodes divided by
  density/160 (3 at 480 dpi) give dp. #area/ui #type/how-to
