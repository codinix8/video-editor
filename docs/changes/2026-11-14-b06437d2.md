## Decisions

- **2026-11-14 – Cancel design for 1.1.7 export** (plan task `b06437d2`). #area/export #type/decision
  - Cancel via a run token (`ExportRun`, one `AtomicReference<Phase>`) checked inside the loops of
    `OverlayAudioRenderer.decodeFresh`/`renderMix` and `VideoConcat.copyTrack`, plus `Transformer.cancel()` on main.
    Rejected: `Thread.interrupt()`/`shutdownNow()` (MediaCodec/MediaExtractor ignore interrupts, cleanup would be
    skipped); coroutines (not used in the export path, larger rebuild).
  - Cancel is accepted until saving to the gallery starts; then the button is disabled. Rejected: aborting the
    MediaStore copy (half-written `IS_PENDING` row for a gain of seconds).
  - The fast-concat fallback must not re-encode after a cancel (catch `CancellationException` before the generic
    catch in `Exporter.export`).
  - Cleanup deletes exactly the files the run tracked (output, overlay mix WAV, partial decode temp); no auto draft
    backup, no prune, segments/session untouched. Rejected: prefix sweep of `cacheDir` on cancel (would delete a
    second export's fresh files); the prefix sweep stays at app start only.
  - UI: BabaCut `Sheet` with `LinearProgressIndicator` in `Sheet.ACCENT`, secondary Cancel button reusing PR-4's
    `btn()` (extracted to `Sheet.actionButton`), Back = cancel, outside tap/swipe ignored, no confirmation dialog,
    "Export cancelled" as Toast. Rejected: status pill (overwritten by the playback ticker), confirmation dialog
    (nothing is lost).
  - Two PRs (engine, then UI); versionCode set only in PR-7b = next free code after the last 1.1.6 tester build
    (rule from `bff4da85`, hub #2917).
  - Insert-time conversion dialog stays non-cancellable in 1.1.7 (out of the approved scope "cancellable export").

## Knowledge

- `Exporter` route C (fast MediaMuxer concat) is reachable only for Pro users: free exports always carry the
  watermark post overlay, which forces the Media3 Transformer route. #area/export
- `Exporter.export` falls back to re-encoding on any `Exception` from the fast concat; a
  `java.util.concurrent.CancellationException` is an `IllegalStateException` and would trigger that fallback unless
  caught first. #area/export

## Known issues

- Overlay mix WAV `cacheDir/ovl_mix_<ts>.wav` is never deleted after an export with overlay sound (not on success,
  not on error, not by the startup sweep, which only matches `export_` and `overlay_video_`); about 11 MB per minute
  of video. Fix planned in PR-7a/PR-7b of the 1.1.7 plan. #area/export #type/bug
- `Exporter.saveToGallery` leaves an `IS_PENDING=1` MediaStore row when the copy fails. Fix planned in PR-7a.
