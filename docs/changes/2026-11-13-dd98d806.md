## Knowledge

- **Incident: returned merges, round 3** (known causes: hub items 2259 and 2378, rounds 1 and 2; this one is new).
  Symptom: "Conflict with main" returns although all record entries go into fragments. Cause: a list in a shared
  config file that every task extends at its end (`docs/_config.yml` `exclude:`), enforced by a CI check that wants
  one exact line per file. Fix: replace the list with a glob and make the check test the built output. Detect
  early: `git log --since=<24h> --format=%h -- <file>` per file over the merged PRs – a non-record file touched by
  most PRs is the next hotspot; `git merge-tree --write-tree origin/main HEAD` before every push.
  #type/incident #area/merge #area/docs #area/ci
- Jekyll `exclude:` entries are `File.fnmatch` patterns without `FNM_PATHNAME`, so `"*.md"` (quoted in YAML) also
  excludes Markdown in subfolders. #tech/jekyll #area/docs #type/how-to
