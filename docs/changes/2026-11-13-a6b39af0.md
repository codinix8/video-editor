## Decisions

- Self-paths in the `pull_request` trigger: `workflow_dispatch` only works for workflow files that exist on the
  default branch, so the workflow file and `scripts/screenshots/**` are trigger paths too; otherwise a change to the
  screenshot run could not be tested before merge. #area/ci #type/decision
- Test data = the emulator's synthetic camera scene (`-camera-back emulated`) plus the typed text "BabaCut Test";
  a review screen needs one recorded segment, and no real camera content exists in the emulator. #area/ci

## Knowledge

- A workflow with only `workflow_dispatch` cannot be run from a PR branch before it is on `main`; give it a
  `pull_request` path trigger on its own file to get a run on the PR. #area/ci #type/gotcha
- The Node.js 20 deprecation annotation appears for the pinned v4 actions (forced onto Node 24, still works); move the
  pins to newer majors in a later chore together with `ci.yml`. #area/ci #type/chore


- An Android emulator in GitHub Actions needs no third-party action: enable KVM via udev rule, `sdkmanager --install
  emulator "system-images;android-35;google_apis;x86_64"`, `avdmanager create avd -d pixel_6`, start
  `emulator -no-window -gpu swiftshader_indirect -no-snapshot` in the background and poll
  `getprop sys.boot_completed`. Owner-path workflows are approved faster without third-party actions. #area/ci #type/howto
