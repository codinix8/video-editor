## Knowledge

- A workflow with only `workflow_dispatch` cannot be run from a PR branch before it is on `main`; a temporary
  `pull_request` path trigger on its own file gives a run on the PR; remove it before the owner merge when the brief
  fixes the trigger list (once on `main`, `gh workflow run <file> --ref <branch>` covers branch tests). #area/ci #type/gotcha
- The Node.js 20 deprecation annotation appears for the pinned v4 actions (forced onto Node 24, still works); move the
  pins to newer majors in a later chore together with `ci.yml`. #area/ci #type/chore
- An Android emulator in GitHub Actions needs no third-party action: enable KVM via udev rule, `sdkmanager --install
  emulator "system-images;android-35;google_apis;x86_64"`, `avdmanager create avd -d pixel_6`, start
  `emulator -no-window -gpu swiftshader_indirect -no-snapshot` in the background and poll
  `getprop sys.boot_completed`. Set `ANDROID_AVD_HOME` explicitly (e.g. `$HOME/.android/avd`, via `$GITHUB_ENV`):
  without it `avdmanager` and `emulator` use different AVD folders on `ubuntu-latest` and the emulator exits at once
  with "Unknown AVD name". Owner-path workflows are approved faster without third-party actions. #area/ci #type/howto
- `adb shell input text` can drop keys on a slow emulator IME, so waiting and retaking does not always help: check
  the uiautomator dump for the full text, clear and retype, and drop the picture if it still fails. #area/ci #type/gotcha
